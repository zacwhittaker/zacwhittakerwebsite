Getting started

Make it yours.

Subscriptions are read-only. You choose the colours; the website supplies the updates.

1

Add a calendar

Tap “Add to Calendar” and confirm the subscription in Apple Calendar. Repeat for each calendar you want.

2

Choose a colour & iCloud

Select your colour and choose iCloud as the account or location to see the calendar on your iPhone, iPad and Mac. On Mac, choose how often it refreshes.

3

Switch off the old combined calendar

If you already subscribed to the full timetable, hide or unsubscribe from it when using the separate calendars.

Want to use an existing calendar instead?

Choose “Download .ics”. On Mac, open Calendar → File → Import, select the file, then choose your existing calendar. Imported copies can be edited, but won’t receive future updates from this website.

Button not opening Apple Calendar?

Copy the address of the “Download .ics” link. On Mac, use Calendar → File → New Calendar Subscription. On iPhone, use Calendar → Calendars → Add Calendar → Add Subscription Calendar, then paste the address.
